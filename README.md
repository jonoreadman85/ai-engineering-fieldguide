# AI Prompting Fieldguide

A practical, self-paced course on writing better prompts for AI tools, progressing from foundations to advanced techniques.

## Course

Open [index.html](index.html) locally to browse the course, or visit the published GitHub Pages site:

<https://jonoreadman85.github.io/ai-engineering-fieldguide/>

The Pages workflow publishes only `index.html`, `assets/`, `lessons/`, and `reference/`. Teaching notes and source tracking remain in the repository but are not included in the site artifact.

## Publish

Push changes to `main`; GitHub Actions builds and deploys the static site to GitHub Pages. You can also run the workflow manually from the Actions tab.
