INTERMEDIATE · 5 MIN

Show the pattern with examples

If the AI understands the task but keeps missing your preferred style or structure, show it one or two examples of what “good” looks like.

The idea

Use a small, representative example when a rule is hard to explain. Make sure the examples match the instruction and cover meaningful variation.

See the pattern

A request like “write this in our usual style” is hard to follow without a sample. A before-and-after example can make the desired transformation concrete. Examples are most useful for tone, classification, formatting, and recurring transformations.

Document writing

Instruction: Rewrite rough status notes into concise updates. Preserve facts, avoid hype, and put blockers first.
Example input: “API work mostly done. Need security review before launch.”
Example output: “Blocker: security review is needed before launch. API work is nearly complete.”
Now: Rewrite [new notes] in the same pattern.

How to use it

Start with one clear instruction and test it. Add examples only if the output still varies in a way that matters. Use examples that represent the real range; contradictory examples confuse the target.

TRY IT · 2 MINUTES

Put it into practice

Give an AI a short example of a transformation you want it to repeat. Include the rule, one input-output pair, and what must not change.
