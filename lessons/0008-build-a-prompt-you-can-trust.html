ADVANCED · 7 MIN

Build a prompt you can trust

If you repeat a task, don’t judge a prompt by one impressive answer. Try it on representative cases and compare each result against explicit criteria.

The idea

Turn repeated use into a small evaluation: collect realistic inputs, define what counts as success, inspect failures, and improve the prompt based on evidence.

See the pattern

Suppose an AI summarizes weekly incidents. Create examples of routine, ambiguous, and high-impact incidents. Check whether each summary preserves facts, identifies impact, and flags unknowns. If it fails the ambiguous case, improve the prompt and rerun the same set.

Repeated work

Task: [the repeated AI task]
Cases: Collect several typical and edge-case inputs.
Criteria: Define 2–4 observable qualities of a good answer.
Review: Record failures and likely causes.
Iteration: Change one thing, then rerun the same cases.

How to use it

A practical starter set can be five to ten real or safely anonymized examples. Score observable qualities such as correct facts, required sections, and appropriate uncertainty. Keep examples that previously failed so improvements don’t regress.

TRY IT · 2 MINUTES

Put it into practice

Choose a task you repeat. Name a few representative cases and two observable criteria you would use to judge the outputs.
