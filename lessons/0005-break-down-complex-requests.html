INTERMEDIATE · 5 MIN

Break complex requests into stages

Big requests often combine several different jobs. Split them into stages when later work depends on earlier findings, or ask the AI to return a plan before it proceeds.

The idea

Use stages to manage dependencies, reduce missed requirements, and create useful review points. Keep straightforward tasks straightforward.

ELI5 · PICTURE THIS

Planning a journey with checkpoints

A long journey is easier to manage as legs with checkpoints. You confirm you reached the right place before committing to the next leg.

Map it back: Each stage has an input and deliverable; a checkpoint lets you correct the direction before the next stage depends on it.

Where it stops: Stages help when work depends on earlier findings; a simple trip across town needs no itinerary.

See the pattern

“Research the market, recommend a product, and write the launch plan” mixes discovery, judgment, and drafting. A staged prompt can first define criteria, then compare evidence, then make a recommendation, and only then draft the plan.

Planning

Stage 1: List the decision criteria and ask questions about missing constraints.
Stage 2: Compare the options against those criteria using supplied evidence.
Stage 3: Recommend an option, state assumptions and risks, and wait for my approval before drafting a detailed plan.

How to use it

Name stages and what each must produce. Add a checkpoint after any stage where your judgment or new information could change what comes next. Don’t ask every model to expose private internal reasoning; ask for concise rationale, assumptions, evidence, or decision criteria instead.

TRY IT · 2 MINUTES

Put it into practice

Take a complex task and break it into at least two dependent stages. Add one point where you want to review the result before it continues.

This quick check looks for cue words only. It cannot judge whether your prompt is clear or whether the AI answer works.

Primary source

OpenAI Reasoning best practices — OpenAI recommends straightforward prompts for reasoning models and says “think step by step” may not improve results; use explicit goals and clear structure.
