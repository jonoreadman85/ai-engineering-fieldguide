ADVANCED · 5 MIN

Improve an answer with targeted follow-ups

When the answer misses, diagnose the miss before rewriting the whole prompt. A specific follow-up can fix a missing fact, wrong format, weak evidence, or misunderstood goal.

The idea

Treat prompt improvement as a loop: compare the answer with the goal, identify the failure, change one relevant instruction, and check again.

ELI5 · PICTURE THIS

A repair ticket for a first draft

When a repair is wrong, “do it better” is a poor ticket. “The handle is loose; tighten it and check it holds” names the defect, requested change, and acceptance check.

Map it back: The miss is the defect; the follow-up is the repair instruction; your quality criterion is the acceptance check.

Where it stops: A targeted prompt can guide revision, but you still need to judge whether the change solved the problem.

See the pattern

If a draft is too long, say “Cut this to 120 words and keep the decision and owners.” If a research answer makes unsupported claims, say “Add sources for the three claims and mark any claim you cannot verify.” Each follow-up names the defect and the desired change.

Any task

Prompt: [your original request]
Miss: [what the answer got wrong or omitted]
Change: [one specific instruction or context change]
Check: [what you will look for in the revision]

How to use it

Don’t stack unrelated complaints. Fix the biggest failure first, then reassess. If the AI cannot know something, provide the missing context or change the task to ask for questions instead of guessing.

TRY IT · 2 MINUTES

Put it into practice

Write a follow-up for an answer that missed an important requirement. Name the miss, give one targeted change, and state how you’ll check the revision.

This quick check looks for cue words only. It cannot judge whether your prompt is clear or whether the AI answer works.
